# Plaxel

Plaxel is a Rust engine and game project focused on high performance and parallelization. This repository contains the engine, editor, and game.

## Engine

The engine is a library used by the game, with an architecture similar to Bevy's ECS and plugin model. It provides the foundations for the game:

- A custom Entity Component System (ECS).
- Physics powered by Rapier3D.
- A math library built on glam.
- A job system for parallel execution.

## Editor

The editor focuses on debugging, inspecting rendering, and profiling. Its tools include:

- **GPU texture viewer:** Inspect loaded textures and textures generated by compute shaders.
- **Render pass node viewer:** Visualize render passes and edit their settings.
- **Scope profiler:** Inspect instrumented scopes and CPU core activity, including idle cores.
- **GPU profiler:** Measure the time each render pass takes in milliseconds.
- **Sampling profiler:** Use Windows ETW to sample function execution without manually instrumenting scopes.
- **RenderDoc integration:** Select "Capture GPU frame" to capture a frame and open it in RenderDoc.

AI is used extensively to develop new editor tools.

## Game

The game is in the prototype stage, aiming to combine elements of Space Engineers and Kerbal Space Program with huge deformable planets and realistic physics.

Current features include:

- Planets with a radius of 6,370 km and deformable terrain built using dual contouring and an octree. Terrain levels of detail (LODs) load as you fly around the planet.
- Water meshes managed by a separate octree, with their own LODs.
- Volumetric clouds driven by a weather map, allowing cloud shapes to vary across the planet.
- Double-precision floating-point coordinates for astronomical bodies. The renderer uses camera-relative coordinates to render with `f32` precision.
- Atmosphere shaders for views from both the surface and space.
